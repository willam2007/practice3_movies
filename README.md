# practicum_movies — многостраничный сайт (React, TS, MUI, Redux)

Практическое задание 3. Предметная область — «Фильмы (TMDB)». Фронтенд-онли, данные локальные (`src/data/`).

## Запуск

```powershell
npm install
npm start
```

## Страницы

| Маршрут | Страница | Что делает |
|---|---|---|
| `/` | Главная | Макет по варианту: горизонтальная галерея + 3 колонки карточек (боковые + центральные) |
| `/movie/:id` | Фильм | Динамическая страница по клику на постер/карточку |
| `/list` | Каталог | DataGrid: фильтрация, сортировка, управление столбцами (тулбар) |
| `/chart` | Диаграммы | Группировка по жанру/языку/году, гистограмма/линейная + таблица |
| `/testing` | Проверь себя | Тест из 6 вопросов 4 типов, состояние в Redux |

## Тест — 4 типа вопросов

1. **Сопоставление (M)** — фильм ↔ режиссёр (drag-and-drop).
2. **Сортировка (S)** — упорядочить фильмы по году (drag-and-drop).
3. **Выбор одного (single)** — radio-кнопки.
4. **Выбор нескольких (multiple)** — чекбоксы.

Всего 6 заданий (2 одиночный выбор + 2 множественный + сопоставление + сортировка). Состояние ответов хранится в Redux (`testing/features/quizSlice.ts`): для M/S — порядок строк, для single — один выбранный вариант, для multiple — массив выбранных. Кнопка «Проверить» считает результат, «Начать снова» сбрасывает Redux и перемешивает.

```
└── index.tsx     роутер + Provider
```
